# 절 오메가 검증전 P3 · 모니터 연습

브라우저에서 바로 하는 절 오메가 검증전 3페이즈 "모니터" 기믹 연습 시뮬레이터입니다.

**플레이:** https://cut-the-leash.github.io/top-p3-monitor/

## 하는 법
1. 내 직업을 고릅니다 (직업 버튼 또는 파티 리스트 칸 클릭).
2. **START** → 3초 카운트다운 후 모니터 디버프가 3명에게 붙고, 보스가 필드 절반에 모니터를 시전합니다 (8초).
3. 파티 리스트로 내 순번을 읽고 **WASD / 방향키**로 자리를 잡습니다. 모니터 대상이면 몸 방향까지 맞춰야 합니다.
4. 8초 뒤 판정 → 사망자 0명이면 "잘했어요~", 아니면 "전멸".

## 우선순위
백마도사 › 전사 › 암흑기사 › 리퍼 › 용기사 › 기공사 › 소환사 › 학자

## 판정 규칙
- 파동포(보스 1 + 모니터 3)는 각각 2명을 노립니다.
  - 범위 안 2명 미만 → 모자란 인원은 나머지 파티원 중 무작위
  - 범위 안 2명 초과 → 범위 안에서 무작위 2명
- 맞은 사람 위치마다 반지름 6의 원형 장판이 터지고, 장판 2개를 맞으면 사망합니다.

## 기타
- 파일 하나(`index.html`)로 동작하며 설치가 필요 없습니다.
- 휴대폰에서는 화면 조이스틱으로 움직일 수 있습니다.
- 기록과 설정은 각자 브라우저에만 저장됩니다.
